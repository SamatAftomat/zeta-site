# Zeta — сайт

Одностраничный сайт для компании **Zeta** (стеклянные и раздвижные перегородки, Петрозаводск).

- Данные: карточка [2ГИС](https://2gis.ru/petrozavodsk/firm/70000001026823746) — цена, фото, контакты
- Статический сайт: HTML + CSS + JS, без сборки
- Стиль: «Сигнальный чертёж» (Unbounded + Manrope)

## Локальный запуск

    python -m http.server 8000

и открыть http://localhost:8000

## Структура

    index.html   — вся страница
    css/style.css
    js/main.js
    img/         — фото работ из галереи 2ГИС
